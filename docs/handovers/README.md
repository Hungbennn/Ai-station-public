# Bàn giao

Thư mục này giữ mẫu bàn giao (`_TEMPLATE.md`), các kịch bản đo cổng chạy thật (`g3-*.sh`, `g6-thu.sh`) và vài tài
liệu thiết kế, sổ tay được docs khác trỏ tới.

Bản public **không đăng nhật ký từng phiên làm việc** của người chủ trạm. Vì vậy một số link trong `docs/plans/` và
`docs/quyet-dinh/` trỏ tới file không có ở đây. Nội dung kỹ thuật cần thiết đã được chưng cất vào `docs/`.
